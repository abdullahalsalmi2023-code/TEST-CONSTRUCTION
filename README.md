# Apex Construction — Demo Website

A demo landing page for a fictional construction company, built as a static site (HTML, CSS, JavaScript — no build step).

## What's inside
- `index.html` — page structure and content
- `styles.css` — all styling (responsive, mobile-friendly)
- `script.js` — mobile menu, demo contact form, footer year

## Run it locally
Just open `index.html` in your browser. That's it.

Or serve it with any static server, e.g.:
```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Sections
- Hero with call-to-action and stats
- Services
- Featured projects
- About + testimonial
- Contact form (demo only — does not send messages)

> This is a demo website. Company name, projects, and testimonials are fictional.
